| A-2 | Will the static sweep for the single timestamp query (AC-S1 / V-15) trip over an existing `os.stat`? | Yes, and it is not yours: `_load_override():1359` calls `os.stat(str(OVERRIDE_PATH))` and reads `st_mode` through `S_ISREG`. The sweep's assertion is "exactly one site reads `st_mtime`", not "exactly one `os.stat` in the file" — report `:1359` as the known non-timestamp hit rather than papering over it or widening the assertion. |
| A-3 | Is `sys.stderr.write(s + "\n")` really byte-identical to `sys.exit(s)`, including the interleaving `install.sh` sees? | The text is: `sys.exit(<str>)` writes the string plus one newline to stderr and exits 1 (P-1). The interleaving is unchanged too: stderr is unbuffered in both, and the buffered stdout is flushed at interpreter shutdown either way, so the merged `2>&1` capture keeps the same order. C-8 requires you to prove it rather than inherit this answer. |
| A-4 | `Done` disappears on runs that now exit 1 — does that break a consumer? | No consumer reads the word. `install.sh:567` branches on the exit status alone, and the OpenRC periodic script is `#!/bin/sh` with one command, so it propagates the status too. The invariant that actually held at HEAD — `Done` printed ⟺ exit 0 — is preserved by K-14, and the set of zero-exit runs is exactly what half 2 changes. |
| A-5 | Can the fixture use synthetic `.srs` bytes, or must it copy the host's real ones? | Synthetic is fine for every step in `02`'s plan, because no step runs the real `sing-box`: `sc.SB_BIN` is a stub at V-1…V-14 and V-8/V-9 stub the `check` return explicitly. `.harness/insight-index.md:25` (real `sing-box check` parses every referenced `.srs` and dies on synthetic bytes) bites only if a step swaps in the real binary — if any step does, that step needs the host's real bytes. |
| A-6 | Is there a smaller form of the three destructuring edits (E-5, E-7) than adding one ignored name each? | There is one neither upstream document considered, and it is not mandated here: starred unpacking (`for tag, fname, status, *_rest in states`, `for tag, _fname, _status, digest, *_rest in before`, `for _tag, fname, status, _digest, size, *_rest in states`). | A-7 | Does `restart_service()` returning `True` when neither init system is set need a guard anywhere? | No, and not for the reason I-4 gives. That arm is unreachable from `cmd_update_rules()` — the call is guarded by `regen_ok and is_running():2804`, and `is_running():2007` returns `False` unconditionally on such a host — and `reload_or_restart():1972` discards the return.
