- `grep` in this project's interactive shell is a **function** wrapping ugrep 7.5.0 while a script gets GNU grep 3.11, and the two disagree — ugrep's `-cv` returns one less than `grep -v | wc -l` on a file with no trailing final newline — so a count taken at the tool layer is not the count the script under test takes; use `/usr/bin/grep` explicitly in any measurement that decides a criterion · evidence: `test/t27/c3i/.harness/insight-index.md`, `-cv`=7 vs piped 8, reproduced on a 5-line synthetic file
- `archive-task.sh:118`'s `header=$(grep -vE '^\s*-\s' …)` is a **content** hazard, not just a count one: command substitution drops the index's trailing non-bullet lines and the filter hoists every mid-file non-bullet line into the header block, so a rotation over such an index silently deletes and reorders lines while leaving `verify_all` F.4 PASS · evidence: `test/t27/c3iii` — 33 lines → 29, trailing blank gone, mid-file marker moved from line 19 to line 9
