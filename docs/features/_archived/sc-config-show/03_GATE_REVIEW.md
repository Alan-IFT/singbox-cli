## Pre-answered developer questions

| id | question | answer |
|---|---|---|
| D-1 | K-5 writes `t("cannot read {path}: {e}", …, e=_plain(str(e)))` with the first argument elided — do I have to pass `path`? | Yes. `t()` is `msg.format(**kwargs)` (`bin/sc:411-413`), so an omitted placeholder raises `KeyError` on the very path that exists to report an error; pass `path=str(CFG_PATH)` and `e=_plain(str(e))`. The other four reused keys take `{path}`, `{path}`+`{problem}`, `{err}` and no placeholder respectively, all verified present in `TRANSLATIONS["zh"]`. |
| D-2 | Should `_redact()` guard against a deeply nested document (`RecursionError`)? | No. `json.loads` raises it before `_redact()` is reached, and the project has already ruled against depth and size caps for a pathological local document (`clash_api()`'s docstring, `docs/dev-map.md:39`). Add no cap, no `try`, no `sys.setrecursionlimit`. |
| D-3 | Where exactly does the `sys.stdout.flush()` go inside K-6's `try`? | Inside it, immediately after the single write. A `sys.stdout.write` into a buffer often never raises; the `EPIPE` surfaces at the flush, and the whole point of `os._exit(1)` is that the interpreter's shutdown flush never runs and therefore never prints "Exception ignored". Do not replace `os._exit(1)` with `sys.exit(1)`. |
| D-4 | Do I need `sc config show`, `--raw`, or room for a future `sc config edit`? | No. `sc config` is bare (Q-1, I-7); `sc config <anything>` is argparse's own exit-2 usage error and needs no code. A future writer command would be `sc config <verb>`, which makes today's bare form its natural default — nothing is bought by anticipating it now. |
| D-5 | Does the help row have to mention the `override.json` limit? | No — GC-6. The limit lives in both READMEs; the help row states the guarantee and the mask literal in the block's column shape (I-12). |
| D-6 | Should the read use `encoding="utf-8"`? | Follow the repo convention (`read_text()` with no argument, as at `bin/sc:339/485/497/1886`); BC-3's decode failure is caught identically either way because K-5 catches `(OSError, ValueError)`. Record GC-7's residual instead of changing the convention in one place. |
| D-7 | `_load_lang()` will traceback before `cmd_config()` on a non-UTF-8 `settings.json` — may I fix it here? | No. Out of scope 6; it travels as RS-2 to the R-25/R-29 pool row. Your own catch tuple is the correct family and is the whole contribution this task makes to it. |
| D-8 | What is printed when the drift record is unreadable or empty? | Nothing — `_drift_state()` returns `None` and no third stderr line is written, exit stays 0 (BC-12, BC-13, I-5). Absent means *unknown*, never *drifted*, and the warning `⚠️` prefix belongs to `_warn_drift()` alone (I-11). |
