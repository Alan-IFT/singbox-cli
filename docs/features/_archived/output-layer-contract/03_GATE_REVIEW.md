## Pre-answered developer questions

| id | question | answer |
|---|---|---|
| D-1 | I-1 line-buffers stdout — do I now delete the redundant `flush=True` and `sys.stdout.flush()` calls? | No. K-4 freezes them, and most are not redundant: `bin/sc:1201`, `:1213` and `:3307` flush **partial** lines carrying no `\n`, which line buffering never flushes, and `:3121` is a **stderr** flush on a stream this task does not touch. Only `:2978`, `:3125` and `:3385` become redundant, and both AC-14 and rule 85's smaller-diff test favour leaving all of them alone. |
| D-2 | Does `t('#')` pass through `str.format`, so `#` could be interpreted? | No. `t()` (`bin/sc:469-471`) calls `.format()` only when it is given keyword arguments, and the six heading call sites pass none; `#` is not a `str.format` metacharacter in any case (only `{` and `}` are), and the `>4` in `f"{t('#'):>4}"` is a format **spec** applied to the returned string, not part of it. |
| D-3 | Do the six English headings really keep every column start offset (AC-3)? | Yes — verified against `bin/sc:2302-2303` versus `:2310-2311` and `:2315-2316`: fields 4/2/10/30/25/9 with two-space gutters put column starts at 0/6/10/22/54/81 in both rows, and `#`=1, `On`=2, `Type`=4, `Name`=4, `Address`=7, `Delay`=5 each fit. HEAD fails at **two** columns, not one: `ls.idx` is 6 in a 4-wide field and `ls.active` is 9 in a 2-wide field. |
| D-4 | May I set `sc.LANG` instead of driving `main()`? | Only for a step that asserts nothing about I-1. `main()` reassigns `LANG` at `bin/sc:3706`/`:3709`, so a `main()`-driven run ignores an assigned `sc.LANG`; but I-1 lives *inside* `main()`, so a step that calls `cmd_ls()` directly runs the unwrapped stream and can prove nothing about FR-6 or FR-7. C-1 and C-2 govern which steps take which path. |
| D-5 | Is `{done}/{total} bytes ({pct}%)` really outside the count-phrase population? | Yes. Q-7 is contract and E-11 is rationale, so Q-7 governs; the phrase is additionally unreachable off a TTY (`bin/sc:1194`, `if tty:`) and so never enters a captured report. `truncated: got {got} of {declared} bytes` stays **in**: it carries no slash in English and is reachable at `{declared} == 1`. `at {at}: … matched {count} elements` stays **out**: `bin/sc:1399` raises only when `len(hits) != 1`. |
| D-6 | Can the six new heading keys collide with an existing key or an indirect `t()` argument? | No. `#`, `On`, `Type`, `Name` and `Address` appear as neither a `TRANSLATIONS["zh"]` key (`bin/sc:131-385`) nor a `t()` first argument anywhere in the file, and the indirect `t(label)` universe — `DOCTOR_MARK` (`:2456`), the ten `DOCTOR_SECTIONS` labels (`:2955-2965`), the probes' static row labels and the rule-set filenames (`:2586`) — contains none of them. |
